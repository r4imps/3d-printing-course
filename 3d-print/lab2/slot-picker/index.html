Slot picker — suction cup to cell

Operator view: robot at the top, front edge at the bottom. Drive: click a cell — up to travel Z, across, down to hover Z (never into a pocket). Edit layout: drag a holder to move it; drag over empty cells to select a rectangle (or click cells), then add a holder. Test: move one glass from the input tray to the output tray (tick Workstation step for the full cycle).

Holders

Arrows move a holder by one cell (← → along the numbers, ↑ ↓ along the letters). "Use selection" replaces the holder's cells with the selected ones. Nothing is written until Save layout.

1. Roles

Glass n is taken from the n-th input cell and put into the n-th output cell (tags on the grid). Without Workstation step: one glass, input tray → output tray, nothing else.

2. Teach points

Go above a pocket, lower the arm with the jog buttons until the cup sits on the glass (pick) or the carried glass sits in place (place), then press Set. XY offset = where the pocket really is relative to the cell centre; it stays with the holder when the holder moves to another cell. Teach at R 33.
Jog mm Pump
Probe
Start a few mm above the surface (or beside the wall) with the jog buttons. Each step records the pose, the Atom ADC and a camera frame into slot-picker/probes/; then the arm returns to the start. It does not detect the touch yet — this is the data to tune that. STOP ends it, rows so far are kept.

Move one glass

Up to travel Z, over From, down to pick Z, suck, carry at travel Z, down to place Z over To, blow, pump off, up. A cell in a holder with a taught XY offset (Teach points) uses that offset. STOP keeps the pump as it is.

3. Run

Loaded input pockets:
The robot does not see which pockets hold a glass: tick only the pockets you loaded, it takes just those (glass n from input pocket n into output pocket n). Speed is set in mg400-base (≤ max). Between rounds take every holder out of the grid and put it back, reload the glasses, do not re-teach. STOP leaves the pump as it is (a carried glass does not fall); Pump Off releases it.

4. Result of the round → docs/refit_test.csv

Ticks are filled from the steps the robot finished; the robot does not see the glass, so check each one and untick what failed.
